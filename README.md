# Necro Summoner Game (代号待定)

暗黑破坏神 2 风格的死灵法师召唤 ARPG，**玩家不直接操作战斗**，全部交给召唤物。

## 当前状态

🚧 概念阶段 / 调研中

## 核心设想

- 主题：死灵法师 + 亡灵军团
- 核心循环：刷怪 → 拾取装备 → 强化召唤物 → 解锁新召唤 → 进入更深层
- 玩家输入：**仅限**召唤选择、装备分配、阵型/优先级指令、技能升级
- 战斗：完全自动结算（参考 Loop Hero）
