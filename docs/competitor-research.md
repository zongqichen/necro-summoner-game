# 竞品调研：死灵召唤类「不亲自操作」ARPG

> 日期：2026-05-29
> 调研方法：领域知识 + 公开发行信息（Steam 直连超时，未做实时数据核实，标 ⚠ 的条目建议手动验证最新版本/销量）
> 核心定位：暗黑 2 死灵法师的「军团骨灰玩法」，但玩家不直接控制角色战斗，全部交给召唤物处理

## 二、核心观察

1. **「死灵召唤」+「玩家完全不操作」的真空地带是存在的**。
   - POE/D4/Last Epoch 的召唤流玩家仍要走位；Undead Horde 2 仍要操作主角；Grim Dawn 宠物流是最接近的，但仍是 ARPG 节奏。
   - 真正「玩家只做编队/装备/技能升级、战斗全自动」的死灵题材产品**几乎没有 3A 或中型作品**，市场空白主要在中型独立游戏区间。

2. **被验证可行的方向**：
   - 自动战斗 + 战利品循环（Loop Hero 证明了「玩家不打也好玩」）
   - 召唤物分槽位、可装备、可命名、可永久死亡（PoE Animate Guardian 玩家文化证明这条情感粘性极强）
   - 移动端轻度玩法（Summoners Greed 证明召唤+自动战斗能跑商业化）

3. **玩家心理需求 / 市场缺口**：
   - 「老了/手残了打不动 ARPG，但喜欢看大军团碾压」的硬核 ARPG 老玩家
   - 「想体验暗黑暴力刷宝节奏，又不想精确操作」的休闲玩家
   - 「喜欢养成 + 收集 + 单位故事」的 RPG 玩家

## 三、差异化机会（建议聚焦其中 1–2 条）

| 方向                             | 说明                                                                                      | 风险                            |
| -------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------- |
| **A. 永久死亡的命名召唤物**      | 每只骷髅/亡灵有名字、出身故事、装备成长；战死即永逝。复刻 PoE Animate Guardian 的玩家文化 | 玩家挫败感强；需要召唤经济平衡  |
| **B. 「指挥官」玩法层**          | 玩家不操作战斗，但可拖拽阵型、指定优先攻击、布置陷阱。战斗自动结算                        | 操作过少容易无聊；要做出深度    |
| **C. 暗黑式刷宝循环 + 自动战斗** | 装备-技能-词缀深度 = D2/PoE，战斗 = Loop Hero                                             | 平衡难度高；联机/PvP 需重新设计 |
| **D. 故事化死灵主题**            | 每一波军团有羁绊（生前职业/死法影响死后能力），叙事 + 收集驱动                            | 文案工作量大                    |
| **E. 移动端纵向竖屏挂机**        | 上下班 5 分钟开一局，离线收益                                                             | 已是红海，需差异题材            |

## 五、给作者的建议（基于本轮调研）

- **最有差异化、风险最低的切入点**：方向 **B + A 组合** —— 「自动战斗 + 永久死亡的命名召唤物 + 阵型/优先级指挥」。
  - 已被 Loop Hero、Iratus、PoE 玩家文化分别验证过单点；组合起来仍是空白。
  - 比纯挂机有深度，比 ARPG 操作要求低，符合你「不用自己操作」的核心诉求。
- **第一原型应只做 1 个场景 + 5 种召唤物 + 1 套装备词缀系统**，验证「看自动战斗」是否足够爽快，再决定加深度还是横向扩展。
