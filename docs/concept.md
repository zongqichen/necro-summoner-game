# 玩法雏形（Concept v0）

> 决策记录：取竞品调研里的 **方向 B + A 组合** —— 阵型/优先级指挥 + 命名召唤物 + 永久死亡。
> 这是已经做出的决定，不再变更直到第一原型跑出来。

## 核心循环

```
进入关卡 → 召唤初始军团 → 自动战斗（玩家旁观）→ 拾取战利品 →
  ├─ 装备分配给指定召唤物
  ├─ 升级法师技能 / 解锁新召唤
  └─ 召唤物战死 → 永久死亡，留下墓碑
→ 进入下一层
```

## 玩家可做的事（**唯一允许的输入**）

1. **召唤** — 消耗尸体/灵魂资源召唤新单位（5 种初始：Skeleton Warrior / Archer / Mage / Tank / Healer）
2. **装备** — 拖拽掉落的装备到指定召唤物的 6 槽位（武器/盔甲/头盔/项链/戒指×2）
3. **阵型** — 网格上摆放召唤物（前/中/后排，左中右）
4. **优先级** — 设置目标策略（最近 / 最弱 / 最强 / 治疗优先 / 法师优先）
5. **法师技能升级** — 法师本人不参战，但提供光环 buff，技能树 8–12 个节点
6. **退出/进入下一层** — 不能暂停战斗，只能整局退出（接近 roguelike）

## 玩家**不能**做的事

- 操作法师走位 / 攻击 / 闪避
- 战斗中切换装备 / 召唤
- 暂停战斗

## 召唤物深度（差异化关键）

- **命名**：每个召唤物生成时随机一个名字 + 一行身世（"Garrick the Smith, killed by his apprentice"），影响初始数值微调
- **永久死亡**：HP 归零即消失，墓碑留在大厅。骨灰可用于稀有召唤
- **成长**：杀敌获得经验，等级提升属性 + 解锁 1 条被动
- **装备印记**：穿戴过的装备会留下印记，召唤物死后印记可继承给下一个

## 战斗规则（auto-combat）

- 实时 + 同屏（不是回合制），节奏接近 Vampire Survivors / Loop Hero
- 关卡 = 一条线性走廊 + 几波怪 + boss
- 召唤物 AI：默认贴脸近战 / 持弓远程 / 站桩法师 / 治疗跟主 tank
- 单局时长 5–10 分钟，符合「上下班通勤一局」的轻度节奏

## 美术风格

**暂定**：暗色像素风（参考 Loop Hero / Iratus）。理由：

- 一个人/小团队能做
- 死灵主题契合
- 不与 D2/PoE 写实风正面竞争

## MVP 范围（第一原型）

- 1 个走廊场景
- 3 种召唤物：Skeleton Warrior / Archer / Mage
- 5 种敌人：Rat / Bandit / Wolf / Skeleton（敌方）/ MiniBoss
- 1 套装备词缀（5 种武器、3 种盔甲）
- 阵型 3×3 网格
- 优先级 3 种（最近 / 最弱 / 最强）
- **暂不**做：永久死亡、命名、印记继承、技能树（v0.2 再加）

## 验证目标

「玩家旁观 5 分钟自动战斗 + 关后捡装备配召唤物」是否爽快。
如果不爽 → 调整节奏/特效/掉率，不要急着加内容。
