# 玩法设计 v0.2（基于深度调研重写）

> 上一版本 v0.1 已被深度调研推翻。本文是新方向的完整设计。
> 一句话定位：**「Iratus 的拼接造物 + Loop Hero 的不操作 + D2 的军团规模 + POE 的小弟情感」**

---

## 1. 核心循环

```
进入关卡（线性走廊）
  → 自动战斗（你旁观）
  → 杀敌掉落「尸块」（骨头/腐肉/灵魂/心脏…）+ 装备
  → 拖尸块到拼接台 → 拼出新召唤物（自动赋予随机名字 + 一行身世）
  → 给召唤物穿装备
  → 调整阵型（3×3 网格）/ 优先级（最近/最弱/血少/治疗位）
  → 进入下一段走廊
  → 召唤物战死 = 永久死亡，留下墓碑（装备掉回背包，但小弟没了）
  → 全军覆没 = 死灵法师本人死，进入「灵魂传承」（Prestige）
```

---

## 2. 玩家可做 / 不可做（**不操作战斗**的边界）

### 2.1 战斗中（**唯一允许**）

- 释放 1 个法师主动技（如 Amplify Damage 诅咒，CD 30s）
- 暂停游戏（看清形势）
- **不能**移动、不能召唤、不能换装备、不能调阵型

### 2.2 战斗间隙（**真正的 gameplay 在这里**）

- 拼接召唤物（消耗尸块）
- 装备分配（拖拽到指定召唤物身上）
- 阵型调整（3×3）
- 优先级（最近 / 最弱 / 最强 / 血少 / 治疗位 / 自定义）
- 法师技能树升级
- 解锁新拼接配方（用稀有尸块）

**心理体验**：你是「指挥官 + 工匠」，不是战士。

---

## 3. 召唤物体系（核心差异化）

### 3.1 拼接系统（来自 Iratus，扔掉回合制）

每个召唤物 = N 个尸块拼起来：

| 尸块 | 来源            | 影响召唤物                  |
| ---- | --------------- | --------------------------- |
| 骨头 | 骷髅 / 大型敌人 | 提供基础结构（HP / 形态）   |
| 腐肉 | 僵尸 / 野兽     | 提供伤害                    |
| 灵魂 | 法师 / 精英怪   | 提供技能槽                  |
| 心脏 | boss / 极稀有   | 解锁**专属技能** + 命名出身 |

**配方示例**：

- 4 骨头 = 骷髅战士（最基础）
- 3 骨头 + 1 灵魂 = 骷髅法师
- 2 骨头 + 4 腐肉 = 僵尸（高血、低速）
- 1 心脏 + 3 骨头 + 1 灵魂 = **命名英雄**（来自被你击杀的 boss 之心）

### 3.2 命名 + 身世（来自 POE Animate Guardian）

每个召唤物**生成时随机名字 + 一行身世**：

- 「Garrick the Smith — 死于学徒之手 — 锻造意志: 受击有 5% 几率反弹伤害」
- 「Maeve the Healer — 因瘟疫失去家人 — 治愈意志: 治疗效果 +20%，但 HP -15%」

身世**影响初始数值微调**（±5–20%），创造「**没有两个一样的小弟**」的感觉。

### 3.3 永久死亡

- HP 归零即永久消失，墓碑留在大厅
- 墓碑可以被「**献祭**」获取灵魂值（法师升级用）
- 装备会掉回背包（不会损失）
- 一只小弟**最大成就**会刻在墓碑上（杀过的 boss / 经历的关卡数）

**为什么这是核心**：永久死亡 + 命名 + 身世 = 「这只小弟是**这一只**，不是替代品」 — 这是 D2/D4/POE 都没做的情感连接。

### 3.4 召唤物成长

- 杀敌经验 → 等级 → 数值
- 升级时随机解锁 1 条被动（"夜行者: 月夜 +30% 移速"）
- 满级（Lv 30）后可以「**继承**」：让墓碑里的某只小弟，把自己的最大成就传给下一只 — 复刻「死灵法师代代相传」的题材浪漫

---

## 4. 装备 / 词缀系统

### 4.1 装备槽（每只召唤物）

6 槽：武器 / 盔甲 / 头盔 / 项链 / 戒指 ×2

### 4.2 词缀类型

| 类型           | 示例                                  |
| -------------- | ------------------------------------- |
| **本体属性**   | +X 伤害 / +X% 攻速                    |
| **召唤物专属** | +X 全军团伤害 / +1 同时召唤上限       |
| **拼接修饰**   | 死后留 50% 概率不消失（仅 Lv5+ 适用） |
| **羁绊**       | 同名小弟两只在场时，互相 +20% 伤害    |
| **诅咒**       | 装备时自身 -X HP，但伤害 +Y%          |

## 5. 进度结构

### 5.1 单局

- 5–8 个走廊片段（每段 2–3 分钟）
- 中段 boss、终段 boss
- 可中途撤退（保留 70% 资源）
- 失败 = 全队没了 → 进入「灵魂传承」

### 5.2 灵魂传承（Prestige，来自挂机游戏 + 死灵主题契合）

死灵法师本人死亡后：

- 选择 1 个**永久 buff**（来自死灵传承的可选树，3 选 1）
- 重新开始，但保留：
  - 解锁过的拼接配方
  - 法师技能树等级
  - 永久 buff
- 失去：
  - 当前小弟（全部）
  - 当前装备

**叙事壳子**：「上一代死灵法师在传承之夜将灵魂注入新人，但其作品都化为尘土」

### 5.3 离线挂机（可选 v0.3 加）

- 离线时按当前最强配置挂机推关，效率 70%
- 上线时可一次结算或观看回放
- 适合上下班节奏

## 6. 与每个竞品的差异化映射

| 竞品                     | 它做什么                     | 我们怎么不一样          |
| ------------------------ | ---------------------------- | ----------------------- |
| **D2 Summonmancer**      | 大军团但要走位/操作          | 全自动                  |
| **D4 Necromancer**       | 献祭机制；少量精英召唤       | 拼接机制；可大可小军团  |
| **POE Animate Guardian** | 1 个永久死亡召唤物，玩家挚爱 | 全军团皆是 AG 体验      |
| **Grim Dawn Cabalist**   | ARPG 节奏，要走位            | 不要走位                |
| **Undead Horde 2**       | 实时召唤 ARPG，玩家亲自打    | 玩家不打                |
| **Iratus**               | 回合制拼接造物               | 实时节奏 + 拼接         |
| **Loop Hero**            | 卡片 + 不操作，无召唤主题    | 死灵召唤 + 不操作       |
| **Vampire Survivors**    | 武器自动 + 移动              | 召唤物代替武器 + 不移动 |
| **Auto Chess**           | 备战 + 自动                  | 装备/拼接代替买棋       |
| **AFK Arena**            | 编队 + 自动战斗 + gacha      | PC 买断 + 拼接养成      |

## 7. MVP（v0.2）范围

最小可验证产品：

- 1 张地图 = 5 段走廊 + 1 boss
- 3 种尸块 + 4 种基础配方
- 5 种敌人（小怪 3 种 + boss 2 种）
- 召唤物：命名 + 身世 + 永久死亡（v0.1 留下的 prototype 已部分实现命名机制）
- 装备：5 武器 + 3 盔甲 + 5 词缀类型
- 阵型 3×3 + 优先级 3 档
- **暂不**做：传承（Prestige）、离线挂机、新地图、技能树、配方解锁、心脏小弟

### MVP 验证目标

测试**最关键的假设**：玩家是否会对「**自己拼出来的、有名字的、会死的**」小弟产生情感连接？

- 信号 +：玩家会给小弟改名 / 截图分享 / 不舍得让它送
- 信号 -：玩家把小弟当数值，不在意死亡

如果信号 -，整个差异化就失败，要回到「军团规模型」改方向。

---

## 8. 美术风格定调（暂定）

- **暗色像素 + 哥特调**：Loop Hero 量级的美术工作量，单人/小团队可承担
- 召唤物用「拼接感」视觉（不同部位明显接缝）— 与拼接玩法呼应
- 关键时刻用全屏 Hold（小弟死亡 / 心脏掉落 / boss 出场）

---

## 9. 后续可能的玩法 v1.0+

- 心脏拼接（命名英雄）
- 配方解锁树（30+ 配方）
- 多张地图 + 各自主题尸块
- 离线挂机
- Roguelike 模式（每局完全重置）
- 协作 / 异步 PvP（你的小弟 vs 其他玩家的小弟）

---

## 10. 不会做的事（明确边界）

- ❌ 玩家亲自移动 / 攻击 / 闪避
- ❌ 实时召唤（必须先拼）
- ❌ 大量随机生成的无名小怪（每个召唤物都有名字）
- ❌ Gacha / 抽卡（PC 买断模式）
- ❌ PvP 实时战斗（异步可以）
