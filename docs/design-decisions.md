## 2026-05-29 · 第三轮（玩家测试反馈）

### D-014 推翻「不操作战斗」回到 Vampire Survivors 范式

- **决策**：玩家**可以**用 WASD / 方向键自由移动；普攻自动；**无主动技**；小弟**自动召唤**（带数量上限 + 多种类）
- **理由**：玩家实测 v0.1.1 反馈「不能移动 = 不像游戏」。「Loop Hero 不操作」的设计在原型阶段无法验证情感，反而首次体验就劝退
- **D-014a 修订（同日）**：去掉 Q/E 主动技，改为完全自动化（移动 + 自动普攻 + 自动召唤）。用「**多种类骷髅**（战士 / 射手 / 法师）+ 升级解锁种类」承担深度，而不是主动按键
- **保留差异化**：拼接造物 + 命名 + 身世 + 永久死亡 + 死灵题材（这四个仍是核心卖点）
- **抛弃**：Loop Hero 不操作（D-008 的一个支柱）；主动按键技能
- **重新定位**：「**Vampire Survivors 移动 + 死灵题材 + 自动召唤多兵种 + 命名永久死亡**」 ≈ Undead Horde 2 但召唤物有名字、有故事、会永久死亡，且玩家完全不主动按技能键
- **MVP 验证目标改写**：「玩家是否会因 5 分钟生存里某只小弟救场而对它产生情感连接」
- **备选**：(A) 折中加方向键但保留无主动攻击 — 体验仍奇怪 / (B) 完全 Loop Hero clone — 已被验证不直观 / (C) 保留 Q/E 主动技 — 玩家测试反馈「希望更自动、更专注移动+走位」

## 2026-05-29 · 第二轮（基于深度调研）

### D-008 玩法定位重写

- **决策**：「Iratus 拼接 + Loop Hero 不操作 + D2 军团 + POE 情感」四合一
- **理由**：第一轮调研太浅；深度调研 (`competitor-research.md`) 后发现 PART 8 矩阵中差异化得分最高的 4 个机制全在不同游戏里被验证过，但**没有任何一款产品组合它们**
- **备选**：纯 Loop Hero clone（无差异化）/ Auto Chess + 死灵题材（已被 Super Auto Pets 抢占）/ AFK Arena clone（手游红海）

### D-009 推翻 v0.1 prototype 中的设计

- **决策**：v0.1 prototype 中「实时召唤、无拼接、无命名」要被推翻，但代码骨架可保留
- **理由**：v0.1 缺最关键的差异化（拼接 + 命名 + 永久死亡的情感模型）；只验证了「自动战斗看着是否爽快」这一点

### D-010 不做手游内购

- **决策**：定位 PC 单机买断（参考 Grim Dawn 700 万 units）
- **理由**：手游 gacha 红海，AFK Arena 量级门槛极高（$1B），单机题材更契合死灵主题

### D-011 离线挂机推迟到 v0.3

- **决策**：v0.2 不做挂机，先验证玩家在「主动 session」中是否爽快
- **理由**：先验证核心循环 → 再加长尾留存

### D-012 永久死亡是核心，不能省

- **决策**：MVP 必须含永久死亡 + 命名 + 身世
- **理由**：这是与所有竞品的**唯一最强差异化点**（POE Animate Guardian 玩家文化已验证情感力）；省了就等于做平凡的召唤 ARPG

### D-013 拼接系统作为「可玩 gameplay」承担「召唤决策深度」

- **决策**：玩家不操作战斗，那么「拼接 + 装备 + 阵型」必须有足够深度
- **理由**：调研 PART 7.1 警告：「不操作」类游戏的最大失败模式是「**看 5 分钟就无聊**」 — 必须有高频选择窗口；拼接 + 装备就是窗口

## 2026-05-29 · 第一轮（部分作废）

### D-001 玩法方向：B+A 组合 ⚠ 已被 D-008 升级

最初决策：阵型/优先级 + 命名 + 永久死亡。第二轮把它扩到「拼接 + 命名 + 永久死亡 + 阵型/优先级」。

### D-002 技术栈：TypeScript + HTML5 Canvas（仍生效）

仍然是 vanilla TS + Canvas，零依赖。

### D-003 平台优先级：PC Web → Steam → 移动（仍生效）

### D-004 美术：暗色像素风（仍生效）

### D-005 节奏：实时（仍生效）

但加了一条：实时**战斗**，但**拼接 / 装备 / 阵型**是非实时（暂停可操作）

### D-006 单局时长：5–10 分钟 ⚠ 调整

- **新决策**：单局 15–20 分钟（5–8 段走廊）
- **理由**：5 分钟太短，召唤物不够有「成长经历」 — 永久死亡的情感冲击需要更长时间发酵
- **参考**：Loop Hero 单 loop 也是 15–25 分钟

### D-007 v0 不做永久死亡 ⚠ 推翻

- **新决策**：v0.2 必须做永久死亡
- **理由**：D-012 — 永久死亡是核心差异化，省了就没卖点
