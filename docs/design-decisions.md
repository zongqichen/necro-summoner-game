# 设计决策日志

每条决策格式：`决策 / 时间 / 理由 / 备选方案`。

---

## 2026-05-29

### D-001 玩法方向：B+A 组合

- **决策**：阵型/优先级指挥 + 命名召唤物 + 永久死亡
- **理由**：竞品调研三个方向（B/A/C）单独都被验证过，组合是市场空白；C（暗黑式词缀深度）放到 v0.3 再考虑
- **备选**：纯挂机（红海）/ Loop Hero clone（无召唤主题）/ POE-like（操作太重）

### D-002 技术栈：TypeScript + HTML5 Canvas（零依赖）

- **决策**：第一原型用 vanilla TS 编译到单个 JS + 一个 HTML，无框架，无 npm
- **理由**：
  - 用户可以双击 HTML 立即玩，无需 install
  - Claude Code 能在一个 session 内迭代到可玩，不卡在工具链上
  - 后期想转 Phaser / PixiJS / Godot 都不困难，因为逻辑层独立
- **备选**：Godot（学习曲线 + 二进制 IDE）/ Unity（重）/ Phaser（依赖管理）

### D-003 平台优先级：PC Web → Steam → 移动

- **决策**：先做浏览器版本（开发友好），再考虑打包 Steam，移动端最后
- **理由**：移动端虽然变现强，但需要触屏适配、内购、推送等额外工作

### D-004 美术：暗色像素风占位

- **决策**：原型阶段用纯色矩形 + emoji 占位，跑通玩法后再委托美术
- **理由**：避免在程序员美术上耗费时间

### D-005 节奏：实时自动战斗，不是回合制

- **决策**：参考 Loop Hero / Vampire Survivors 节奏
- **理由**：用户提的是"暗黑 2 玩法"，回合制不符合节奏感；竞品 Iratus 已占据回合制赛道

### D-006 单局时长：5–10 分钟

- **决策**：单关 5–10 分钟，关卡间存档
- **理由**：契合通勤场景；rogue-lite 单局节奏

### D-007 v0 不做永久死亡

- **决策**：v0.1 召唤物战死后只是消失，不留墓碑
- **理由**：先验证战斗本身好不好玩；永久死亡情感重量需要更完整的命名/身世系统支撑
