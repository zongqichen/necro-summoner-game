NECRO SUMMONER

A necromancer auto-combat prototype
Move, raise named skeletons, watch them permadeath

▶ Play in browser Source on GitHub

What is this

  • 5-minute survival run — Vampire-Survivors-style movement and auto-attack, but the army is summoned for you.
  • Auto-summoned skeleton legion — warrior, archer, mage; unlock new types as perks when you level up.
  • Each minion is a person — random first name, title, and backstory. Their permadeath is logged.
  • Single-screen arena — enemies enter from any of the four edges, difficulty ramps every minute, BOSS at 5:00.
  • Zero-dependency — pure HTML5 Canvas + vanilla JS. No build step. ~7 MB total. Free art under CC-BY-SA 3.0.

Controls

Desktop: WASD / ↑↓←→ to move · Space pause · R restart

Mobile: drag anywhere on the play area to move

Auto-attack and minion summoning happen on their own — focus on positioning.

Languages

The game UI is available in English and 中文 (Chinese). Use the language switcher in the side panel.

Status

Pre-alpha prototype. The current build (v0.2) tests the core loop: does an auto-summoned, named, mortal minion create emotional attachment in 5 minutes?
