# 项目核心定位

主题：死灵法师 + 亡灵军团召唤
玩法参考：暗黑破坏神 2（节奏、刷宝、装备词缀深度）
关键差异：**玩家不操作战斗本身**，输入只限于召唤选择 / 装备 / 阵型 / 优先级 / 技能升级

**Why:** 用户希望「喜欢暗黑暴力刷宝节奏，又不想精确操作」，市场上死灵主题 + 完全自动战斗的产品几乎为空白（Grim Dawn 宠物流最接近但仍是 ARPG 节奏）。

**How to apply:**

- 涉及玩法决策时，优先保留「自动战斗」边界，不要不知不觉滑回操作型 ARPG
- 涉及竞品对比时，参考 [[competitor-research]] 中的差异化方向 B+A 组合（命名召唤物 + 永久死亡 + 阵型/优先级指挥）
- 第一阶段以验证「看自动战斗」是否足够爽快为目标，避免过早扩张内容
